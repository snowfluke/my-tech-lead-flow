# Terminology

Review the terminology ledger. Each item must have one canonical term, a source, part of speech, meaning, and approved abbreviation policy. Check that long official terms (over three words) are introduced in full at first use and shortened only by an approved method — explanation-plus-short-form, or hyphenation of a genuine single unit, never invented shortenings (rule 2.2). Check that a recurring action or component uses the same term and the same sentence pattern every time it appears (rule 9.4), not just the same vocabulary. Flag synonym drift — a second term introduced for an already-ledgered item — as `MAJOR`. Flag a ledger entry with no source or an `UNVERIFIED` approval status the same way; it blocks the gate per [audit/00-severity.md](00-severity.md) unless explicitly accepted.
