# Content classification

Check that each block is correctly labeled `PROCEDURE`, `DESCRIPTION`, `SAFETY`, `NOTE`, or `LITERAL`, per [workflow/01-classify.md](../workflow/01-classify.md). A note must not contain an instruction, limit, result, or safety control (`BLOCKER` if safety-critical, `MAJOR` otherwise — see [audit/00-severity.md](00-severity.md)) — apply the read-without-notes test: the procedure must stay fully doable with every note deleted. A procedure must not hide a command in descriptive prose, and a description must not be phrased as an implicit command. Check every `LITERAL` boundary against [rules/literals-and-identifiers.md](../rules/literals-and-identifiers.md): confirm the literal is exact (spelling, capitalization, punctuation, spacing preserved even if non-STE) and that it was not accidentally "corrected," and confirm nothing outside a genuine literal was wrongly excluded from vocabulary checking to dodge a finding.
