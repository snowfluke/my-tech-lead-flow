# 02 — Plan

Create a ledger with: source term, canonical term, part of speech, approved meaning, source/glossary reference, technical-noun or technical-verb category, and allowed abbreviation. Mark unknown values `UNVERIFIED`.

Map each block to the applicable rules. Identify literals and items whose exact meaning must not change. For procedures, list prerequisites, one action per step, completion criteria, limits, and expected results. For safety, identify hazard, exposure, control, and consequence. Resolve ambiguity with the subject-matter source before wording it.
